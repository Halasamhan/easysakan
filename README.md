# EasySakan

Full-stack web application (PHP + React) for real estate, transportation, and services booking platform.

## Tech Stack
- PHP (Backend)
- MySQL
- React (Frontend - Vite)
- HTML, CSS, JavaScript

## Features
- User authentication
- Listings management
- Booking system
- Admin dashboard
- Service & transport modules

## Project Structure
- /easy-sakan-react → React frontend
- / (root) → PHP backend
